**SubOptimal is our freshman engineering final project made to compete in UCF's 2026 Great Naval Orange Race (GNOR EGN 1007C)**

> This is currently the record holder at 7 seconds.

## GNOR
The Great Naval Orange Race is a competition all freshman engineering students must compete in every year. The goal is to transport a naval orange around the reflection pond in as short a time as possible. The acception being submarines which are allowed to go under the divider in the center of the pond and go about 1/4 the distance as boats. This is why we decided to design a submarine for our final project.

## About SubOptimal
SubOptimal is a quad motor autonoumus submarine with its entire goal to make it about 15 meters in under 9 seconds which was the previous record for the past 8 years. SubOptimal consists only of a BNO085 IMU, 4 a2212 1000kv brushless motors, 4 30 amp ESC, a esp32-S3 r16n8, a reed switch for activation and a buzzer for feedback and status pings.

## Code
This code is completely rewritten from the code given and not recommened to run on other boats but rather to use as a refrence. There are additional python and Arduino scripts, the Arduino scripts are used to calibrate the ESCs and IMU. The python scripts are for data analysis and optimal propeller calculation.
